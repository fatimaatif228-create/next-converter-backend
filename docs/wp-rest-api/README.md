# WP REST API Notes

This folder contains sample REST API responses from the local WordPress site.

## Files

- `all-endpoints.json` - all available REST API routes
- `posts-sample.json` - sample response from `/wp/v2/posts`
- `pages-sample.json` - sample response from `/wp/v2/pages`
- `media-sample.json` - sample response from `/wp/v2/media`

## Notes

The posts endpoint returned the default `Hello world!` post.

The pages endpoint returned the default `Sample Page`.

The media endpoint returned an empty array because no media files have been uploaded yet.
