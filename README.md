# repress-api

Backend API for the Next Converter project built with NestJS.

## Prerequisites

* Node.js
* npm

Verify installation:

```bash
node -v
npm -v
```

## Installation

```bash
npm install
```

## Running the App

```bash
# development
npm run start

# watch mode
npm run start:dev

# production mode
npm run start:prod
```

The API runs by default at:

```text
http://localhost:3000
```

## Project Structure

```text
src/   - Application source code
test/  - End-to-end tests
dist/  - Compiled output (generated automatically)
```

## Testing

```bash
# unit tests
npm run test

# e2e tests
npm run test:e2e

# test coverage
npm run test:cov
```
